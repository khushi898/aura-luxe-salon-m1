# Aura Luxe Salon

A responsive website for Aura Luxe, a luxury beauty salon in Jaipur. Visitors can see our services and prices, browse the gallery, and send a booking request.

**Live site:** https://aura-luxe-salon-m1.vercel.app



- **Home:** hero section with Book Now and Call Us buttons, a "Why Choose Aura Luxe" section and client testimonials
- **Services:** 6 service cards with photos and starting prices, plus a booking call-to-action
- **Gallery:** a responsive photo grid with a hover zoom effect
- **Contact:** a booking form, address, opening hours and a Google Map

## Built With

- HTML5 with semantic tags (`header`, `nav`, `main`, `section`, `article`, `figure`, `footer`, `address`)
- Tailwind CSS v4 (CLI)
- JavaScript (only for the dark mode toggle)
- Git and GitHub, with feature branches and pull requests
- Vercel for deployment

## Features

- **Mobile-first responsive design** tested at 375px, 768px and 1280px
- **Flexbox** for the navbar and the "Why Choose Us" cards
- **CSS Grid** for the hero, services, gallery and testimonials
- **Accessible form** with a label for every field, correct input types (`tel`), `required` fields and autocomplete
- **Dark mode toggle** that follows the system theme on the first visit and remembers your choice with `localStorage`
- **Keyboard friendly:** every link, button and input shows a visible focus outline
- **Meaningful alt text** on all images
- `aria-current` on the active nav link and `aria-label` on the toggle button
